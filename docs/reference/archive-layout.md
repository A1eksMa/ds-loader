# Раскладка архива и карантина

Источник: `src/app/ingest.py`.

## Успешно обработанные → `archive/`

```
<archive_dir>/
├── crm/
│   ├── crm_2026-08-24_18-08-16.json
│   └── crm_2026-08-25_09-00-00.json
└── erp/
    └── erp_2026-08-24_18-09-00.json
```

- поддиректория на источник, по его имени; создаётся при отсутствии;
- имя файла — без микросекунд (`<source>_YYYY-MM-DD_HH-MM-SS.json`);
- перемещение происходит **после** записи в журнал (см.
  [`../explanation/exactly-once.md`](../explanation/exactly-once.md)).

## Ошибки → `quarantine/`

```
<quarantine_dir>/
└── crm/
    ├── crm_2026-08-24_18-08-16_552252.json   ← исходное имя, с микросекундами
    └── crm_2026-08-24_18-08-16_552252.json.err
```

Сюда файл уходит, если:

- `ds load` вернул ненулевой код (в `.err` — его stderr/stdout);
- метка времени в имени не парсится в дату.

В карантине имя **сохраняется как было** (с микросекундами) — чтобы файл можно было
разобрать и, при желании, вернуть в `update_dir` после починки.

## Журнал → `ledger_path`

JSONL, по строке на успешно загруженный файл:

```json
{"key":"crm_..._552252.json:1a2b3c4d5e6f7a8b","file":"crm_..._552252.json","source":"crm","dt":1787602096,"loaded_at":1787602100.5,"stdout":"loaded 6 transaction(s)"}
```

`key` = `<имя файла>:<sha256(содержимого)[:16]>`. Битые строки при чтении пропускаются —
журнал остаётся рабочим.
